This is a self-paced experiment, should take around 20-30 minutes. Please ensure you have Python installed on your system to launch the web-based experiment setup. To start the study, run the following from the root:

```bash
python3 -m http.server 8080
```  

And then use a browser to access the webserver from http://0.0.0.0:8080/.

Before the actual experiment starts, you need to fill out the anonymized questionnaire regarding your Mandarin ability and consent form for participation in the study. Only start the study if you consent to everything in the form. You can withdraw your consent at any point. Please email baronia3@illinois.edu for any questions or concerns. 

You will be shown an image of colored shapes and be asked a question about it. Your job is to answer the question with one of three options:

- 是的，没错
- 不，不是真的
- 奇怪的问题

Answer the question to the best of your abilities. There are 425 such questions. At the end, a CSV file with your responses will be generated. DO NOT EDIT THIS FILE. Email it to baronia3@illinois.edu once you are done with the subject line "LING 514 Experiment Results".
